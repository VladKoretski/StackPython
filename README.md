# Проверка сбалансированности скобок

Реализация стека (LIFO) на Python и решение задачи проверки
правильности расстановки скобок `()`, `[]`, `{}`.

## Описание

Класс `Stack` реализует абстрактный тип данных «стек» со стандартными методами:

| Метод       | Описание                                                    |
|-------------|-------------------------------------------------------------|
| `is_empty()`| Проверяет, пуст ли стек. Возвращает `True` или `False`      |
| `push(item)`| Добавляет элемент на вершину стека                          |
| `pop()`     | Удаляет и возвращает верхний элемент                        |
| `peek()`    | Возвращает верхний элемент без удаления                     |
| `size()`    | Возвращает количество элементов в стеке                     |

Функция `check_brackets(string)` проверяет, является ли строка
сбалансированной последовательностью скобок.

## Примеры
```text
Сбалансированные:
(((([{}]))))
[([])((([[[]]])))]{()}
{{[()]}}

Несбалансированные:
}{}
{{[(])]}}
[[{())}]  
```
